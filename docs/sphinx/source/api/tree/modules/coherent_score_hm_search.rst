Purpose
-------

Coherent score marginalization routines for HM searches.

Module summary
--------------

Define class \\\`\\\`SearchCoherentScoreHMAS\\\`\\\` that computes the coherent score (marginalized likelihood over extrinsic parameters) for aligned-spin, (l,m) = [(2, 2), (3, 3), (4, 4)] waveforms.
