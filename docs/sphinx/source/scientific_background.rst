Scientific Background and References
====================================

This page lists core papers that motivate major components of the GWIAS-HM pipeline.
For the full paper-to-code mapping table, see ``references/REFERENCES.md`` in the repository.

Core method papers
------------------

- `2310.15233 <https://arxiv.org/abs/2310.15233>`_
  Template-bank strategy for higher harmonics and cost reduction.
- `2405.17400 <https://arxiv.org/abs/2405.17400>`_
  Mode-by-mode HM search pipeline and non-Gaussian corrections.
- `2404.02435 <https://arxiv.org/abs/2404.02435>`_
  Fast marginalization for detection/statistical inference.
- `1806.08792 <https://arxiv.org/abs/1806.08792>`_
  Relative-binning lineage used in local trigger/refinement ideas.

Pipeline lineage and robustness papers
--------------------------------------

- `1902.10341 <https://arxiv.org/abs/1902.10341>`_
  Early version of the search pipeline and operations.
- `1908.05644 <https://arxiv.org/abs/1908.05644>`_
  Handling non-stationary and non-Gaussian detector noise.
- `1904.07214 <https://arxiv.org/abs/1904.07214>`_
  Earlier coherent-ranking construction; Appendix is relevant to current intrinsic-marginalization caveats.

Recent search-result context
----------------------------

- `2312.06631 <https://arxiv.org/abs/2312.06631>`_
  O3 results with higher-harmonic-enabled search products.
- `2507.01083 <https://arxiv.org/abs/2507.01083>`_
  Search context for intermediate mass-ratio inspirals.
